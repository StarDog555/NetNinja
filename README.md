---

# Installation

### Requirements

At Least **Python 3** or higher

---

> **Note**: Run Theses In Project's Root Dir

First Begin By Installing Required Libs By:
```bash
pip install -r requirements.txt
```
After Run Program by:
```bash
python3 Main.py
```
And Thats It...
